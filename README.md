# AbdulFan-Portfolio

> The official digital presence and interactive creative portfolio of **Abdul Umar Sahan Nethmina** — Novelist, Keynote Speaker, Vocalist, and Creative Visionary behind **[AbdulFandom](https://abdulfandom.lk/)**.

---

## 🌟 Overview

A luxury, dark-aesthetic portfolio website crafted with smooth glassmorphism, responsive architectural geometry, and cinematic storytelling. It converges literature, transformative public speaking, and musical emotion into an immersive web experience.

- **Official Website:** [https://abdulfandom.lk/](https://abdulfandom.lk/)
- **Author & Personality:** Abdul Umar Sahan Nethmina
- **Creative Banner:** AbdulFandom

---

## ✨ Features

- **01 — Hero**: High-impact editorial introduction with interactive canvas backdrop and brand monogram.
- **02 — Philosophy & Pillars**: 5-pillar polymath framework with dynamic timeline metrics.
- **03 — Literary Works (The Writer)**: Interactive 3D bookshelf featuring **32 published novels and masterworks** with genre filters, live search, and full modal book reader.
- **04 — Keynote & Stage (The Speaker)**: Responsive stage hero card, signature oratory topics, and speaking engagement inquiries.
- **05 — Musical Releases (The Singer)**: Interactive vinyl audio studio player, animated waveform visualizer, and track selector.
- **06 — Brand Atelier (AbdulFandom)**: Direct showcase of the official AbdulFandom brand, signature merchandise, bespoke publishing editions, and direct store links (`abdulfandom.lk`).
- **07 — Visual Archive**: Masonry photo gallery with category filter and lightroom zoom.
- **08 — Private Concierge (Contact)**: Direct booking, literary inquiries, and press relations.

---

## 🛠️ Tech Stack & Architecture

- **Markup & Layout:** HTML5 Semantic Structure, Mobile-first Responsive Design
- **Styling:** Vanilla CSS3 with Custom Component Architecture (`assets/css/components/`)
  - Frosted Glassmorphism (`backdrop-filter`)
  - Champagne Gold Accents (`#d4af37`, `#e5c158`)
  - Capsule Pill Geometry & Specular Glows
- **Interactivity:** ES Modules (`assets/js/components/`)
  - Smooth Scrolling (`Lenis`)
  - Interactive 3D Bookshelf & Excerpt Viewer
  - Audio Waveform Simulation
  - GPU-accelerated Scroll Reveal & Particle Engine
- **Server:** Node.js HTTP static server (`server.js`)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Installation & Local Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Dinusha-Fernando/AbdulFan-Portfolio.git
   cd AbdulFan-Portfolio
   ```

2. Start the local server:
   ```bash
   npm start
   # or
   node server.js
   ```

3. Open in your browser:
   ```
   http://localhost:3000/
   ```
